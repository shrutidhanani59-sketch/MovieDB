# 🎬 MovieDB

A MovieDB built using **Node.js, Express.js, MongoDB, and Mongoose**. This project allows users to perform CRUD operations such as adding, viewing,  updating, and deleting movies.

## 🚀 Features

- Add New Movies
- Get All Movies
- Get Specific Movie
- Update Movie 
- Delete Movies


## 🛠️ Technologies Used

- Node.js
- Express.js
- MongoDB
- Mongoose
- Postman
- JavaScript (ES6 Modules)
